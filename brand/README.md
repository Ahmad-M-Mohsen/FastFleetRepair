# Fast Fleet Repair: logo files

The Hex Badge logo and the horizontal logo. All lettering is converted to outlines, so every file opens and prints
correctly without the fonts installed.

## Which file to use

| File | Use it for |
|------|------------|
| `fast-fleet-repair-badge.svg` / `.png` | The main logo, on amber, white or light backgrounds: print, signs, shirts, hats. |
| `fast-fleet-repair-badge-on-dark.svg` / `.png` | The badge on charcoal or black (truck doors, dark shirts). An amber edge keeps it from disappearing. |
| `fast-fleet-repair-badge-one-colour.svg` / `.png` | One ink only: vinyl decals, stamps, embroidery, engraving, one-colour print. Shown in charcoal; the inside and the banner lettering are see-through, and a printer can swap the ink colour. |
| `fast-fleet-repair-badge-avatar.png` | Profile pictures: Google Business Profile, Facebook, Instagram. 1024 × 1024, survives a circle crop. |
| `fast-fleet-repair-logo.svg` / `.png` | Horizontal logo on light or amber backgrounds: website header, letterhead, invoices, email signature. |
| `fast-fleet-repair-logo-on-dark.svg` / `.png` | Horizontal logo on charcoal or black. |
| `fast-fleet-repair-icon.svg`, `icon-512.png` | The hex "F" alone, for spaces too small for the full logo. |
| `apple-touch-icon.png`, `favicon-32.png` | Website icons (iPhone home screen, browser tab). The site links both. |

The SVG files are the masters: send those to sign makers, printers and embroiderers, and scale them to any size.
PNG files have transparent backgrounds, except the avatar (amber) and the iPhone icon (charcoal).

## Colours

| Colour | Hex | RGB |
|--------|-----|-----|
| Amber | `#F2A51A` | 242, 165, 26 |
| Charcoal | `#212225` | 33, 34, 37 |
| Sunburst rays | `#F7C46A` | 247, 196, 106 |
| Off-white (banner lettering) | `#F4F2EE` | 244, 242, 238 |

No Pantone or CMYK values are set yet. For printed work, have the printer match the amber to `#F2A51A` on a proof.

## Fonts for text set next to the logo

- **Teko**, bold and semibold: headlines ("FAST", "24/7 ROADSIDE RESCUE").
- **Michroma**: the spaced-out "FLEET REPAIR".

Both are free from Google Fonts under the SIL Open Font License.

## Using the logo

- Keep clear space around the logo of at least one tenth of its width on every side.
- Smallest sizes: the badge at 50 mm / 200 px wide (below that "24/7 ROADSIDE RESCUE" stops being readable; use the
  horizontal logo or the hex icon instead); the horizontal logo at 30 mm / 130 px wide.
- Don't stretch, rotate or recolour it (apart from the one-colour file), add shadows or effects, or place the
  full-colour badge on a busy photo.
